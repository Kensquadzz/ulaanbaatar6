## Information the current prototype processes

The current build does not require an account and does not ask for a person's name, email address, phone number, contacts, photographs or microphone recordings.

The game stores a small number of local settings in the device/browser's local storage, such as language, graphics quality, camera sensitivity, FPS preference and the last successful weather observation. This data stays on the device unless the user clears the app's storage.

The game does not currently request device GPS permission. Coordinates shown in the HUD are the in-game player's coordinates in the bundled Ulaanbaatar map, not a reading of the user's real-world device location.

## Weather service

The game can request current weather for a fixed point in central Ulaanbaatar from Open-Meteo (https://open-meteo.com/) approximately every five minutes while the game is active. The request includes fixed city coordinates and weather variables; it does not include the player's device GPS coordinates. Open-Meteo and the hosting/network providers may process normal request metadata such as IP address under their own policies.

Weather data attribution shown in the game: Open-Meteo.com (CC BY 4.0).

## Other third parties

The game downloads its own bundled map, terrain and game assets from the app package or its configured hosting provider. It does not currently include advertising SDKs, in-game analytics SDKs, user accounts, social login or user-to-user messaging.

## Audio, camera and location

The current build uses synthesized sound through the device audio system. It does not record microphone input, take photographs, or request device location permission.

## Retention and deletion

Local preferences and the cached weather observation remain in app storage until they are overwritten or the user clears app data / removes the app. There is no account profile or server-side player save system in the current build.
