# Local setup

## 1. Tests without Unreal (any OS, 5 minutes)

Needs CMake, a C++17 compiler and Python 3.10+.

    pip install -r pipeline/requirements.txt
    scripts/test_all.sh

## 2. Rebuild the map data (optional; tiles are already in data/tiles)

    cd pipeline
    python -m ub6pipeline.fetch_overture ../data/raw     # downloads only the slice bbox
    python -m ub6pipeline.build_tiles ../data/raw ../data/tiles
    python -m ub6pipeline.preview ../data/tiles ../docs/slice_preview.png ../core/build/ub6tool

To grow the map, widen `SLICE_BBOX` in `pipeline/ub6pipeline/config.py` and rerun.

## 3. Weather server

    cd server && python -m ub6server.app        # http://127.0.0.1:8080/v1/world

Optional: `GOOGLE_WEATHER_API_KEY` enables Google as the first provider. For phones, deploy
the server somewhere reachable over HTTPS and put its URL in
`unreal/Ulaanbaatar6/Config/DefaultGame.ini` (`ServerBaseUrl`).

## 4. Unreal project (Windows or macOS with a GPU)

1. Install Unreal Engine 5.5 from the Epic Games Launcher with **Android** and/or **iOS**
   target platforms. Visual Studio 2022 (Windows) or Xcode (macOS).
2. Run `scripts/sync_data.sh` (copies tiles into `Content/UB6Data`).
3. Right-click `unreal/Ulaanbaatar6/Ulaanbaatar6.uproject`, generate project files, build
   the `Development Editor` target. **First compile has never been done**: send back the
   compiler output and it will be fixed.
4. Start the weather server, press Play. Keyboard: WASD, mouse, Space, Shift, E (use/enter/exit),
   C (camera), R (reverse). A mouse click acts as a finger, which shows the touch controls.

## 5. Android

Android Studio with the SDK/NDK/JDK versions Epic lists for 5.5, then
`UE_ROOT=... scripts/build_android.sh`. Produces APK and AAB. Store builds need your own
keystore (never commit it).

## 6. iOS

A Mac with Xcode and an Apple Developer Program team, then
`UE_ROOT=... IOS_TEAM_ID=... scripts/build_ios.sh`. Produces an IPA; the Xcode workspace is
generated by Unreal under `Intermediate/ProjectFilesIOS`.
